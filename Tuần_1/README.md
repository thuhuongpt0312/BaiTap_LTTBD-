# Student Profile App (Hồ sơ sinh viên)

Màn hình hồ sơ sinh viên theo mockup: nút quay lại, nút thẻ sinh viên, ảnh đại diện tròn, họ tên và mã sinh viên.

## Chạy thử
Mở `index.html` bằng trình duyệt, hoặc chạy server cục bộ:

```bash
python3 -m http.server 8000   # rồi mở http://localhost:8000
```


## Công cụ sử dụng
| Công cụ | Vai trò |
|---|---|
| HTML5 / CSS3 / JavaScript (thuần) | Xây dựng giao diện, không cần build |
| Google Fonts – Be Vietnam Pro | Font hỗ trợ tiếng Việt |
| VS Code (+ Live Server) | Soạn code và xem trực tiếp |
| Git & GitHub | Quản lý phiên bản và lưu trữ |
| Chrome DevTools (Device Toolbar) | Kiểm tra giao diện trên điện thoại |
| Figma (tuỳ chọn) | Thiết kế mockup |
